# Speaktogrow26

## Ms Shirley Daily English & SPM Speaking

Student-facing static website for daily English and SPM Speaking practice.

## Pages

- `index.html` - Daily English Games
- `spm.html` - SPM Speaking Corner
- `teacher.html` - private teacher dashboard

The teacher dashboard is kept off the student navigation and should only be shared directly with Ms Shirley.

## Deploy

This is a static HTML/CSS/JavaScript site and can be deployed on Vercel.
